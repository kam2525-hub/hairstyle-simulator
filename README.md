# HairStyle Studio (ヘアスタイル シミュレーター)

顔を変えずに、男子・女子それぞれのヘアスタイルやカラーをシミュレーションできるブラウザ完結型のWebアプリケーションです。

## 主な機能
- **Men's / Women's 切り替え**:
  - メンズ: ナチュラルマッシュ、センターパート、スパイキーショート、ニュアンスパーマ、ウルフカット
  - レディース: 切りっぱなしボブ、シースルーミディアム、ゆるふわロングウェーブ、ハンサムショート、ストレートロング
- **リアルタイム ヘアカラー変更**:
  - ナチュラルブラック、ダークブラウン、アッシュグレージュ、ミルクティーベージュ、ハイトーンブロンド、カシスワインレッド、オリーブアッシュ、ピンクブラウン
- **直感フィット調整**:
  - キャンバスドラッグ操作（位置移動）
  - 微調整スライダー（拡大縮小・上下・左右・回転・横幅比率）
  - Before確認（長押し比較）
- **安全・完全無料**:
  - 画像はサーバーにアップロードされず、ブラウザ内で完結して動作します。
- **画像保存**:
  - シミュレーション結果をPNG形式でダウンロード可能。

## 使い方
1. `index.html` をブラウザ（Google Chrome, Edge, Safari等）で開きます。
2. 「写真をアップロード」から正面からの顔写真を選択するか、「男性/女性モデルで試す」をクリックします。
3. 好きな髪型やカラーを選び、キャンバスのドラッグやスライダーでフィットさせます。
4. 「画像を保存」ボタンでシミュレーション結果をダウンロードできます。
